# 📧 AI Email Ghostwriter

An AI-powered full-stack web application that transforms rough notes into professional, polished emails based on selected tones.

## ✨ Features
* **User Authentication:** Secure Signup and Login workflows using JWT and hashed passwords.
* **AI Generation:** Instant email drafts generated from bullet points with customizable tones.
* **Saved Email History:** Store generated drafts automatically in MongoDB and manage past emails.
* **Responsive UI:** Clean React interface with custom dynamic layouts.

## 🛠️ Tech Stack
* **Frontend:** React.js, CSS3, React Router
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas, Mongoose
* **Authentication:** JSON Web Tokens (JWT), bcrypt.
